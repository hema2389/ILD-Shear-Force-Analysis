# Influence Line Diagram for Shear Force at Point D

Analysis of a continuous beam using the Müller-Breslau Principle to determine the Influence Line Diagram for shear force at point D.

## Problem Description
- Continuous beam with supports at A (pinned), B (roller), and C (roller)
- Span AB = 4m, Span BC = 4m
- Point D located at 6m from A (2m from B)

## Usage
```bash
pip install -r requirements.txt
python ild_calculator.py
```

Uses Müller-Breslau Principle with matrix flexibility method...
